{# ============================ DIALOGS ============================ #}

  
    
    
    Apply these physical settings?
    
    
    
    
    This queues a move. Check its result in the queue; the recorded targets remain visible if the move fails.
    
    
    
  
    
    


  
    
    
    Stop the running scan?
    
    
    Pauses at the next shot boundary, then stops gracefully. The shots already taken keep their rows; the box returns to STANDBY. This can take a while.
    
    
    
  
    
    


  
    
    
    Clear the waiting items?
    
    
    The running scan is not affected.
    
    
    
  
    
    


  
    
    
    An item is already waiting
    
    
    The manager runs one item behind the running one. Replace the waiting item with this scan?
    
    
    
  
    
    


  
    
    
    Measure shot offsets?
    
    
    Drives the trigger box OFF, waits the set quiet, fires single shots and reads every device's timestamp.
    
    
    
  
    
    


  
    
    
    Replace preset ?
    
    
    A preset of that name already exists in the configs tree. Replacing it changes what everyone submits under that name.
    
    
    
  
    
    


  
    
    
    Preflight found things to acknowledge
    
    
    The request is valid and the worker is ready. Each item is a question, not a refusal; tick it to continue with it on record.
    
    
      
    
      Acknowledged checks are stamped continued in the submission record that rides with the run.
