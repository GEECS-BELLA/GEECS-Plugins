How a recipe runs

inputWhich device's files to read: a camera image or a trace. input.siblings joins several cameras' traces.
stepsAn ordered list of processing steps. Each sees the previous step's output, so order matters.
measureOne measure turns the processed frame into scalars, which land as columns in the scan's s-file.
summariesScan-level figures: one image per bin, a waterfall of traces, or the averaged frame.
