# Acquisition Tutorial

!!! warning "Under construction"
    The dedicated end-to-end acquisition tutorial is a stub. The
    **[GEECS Scanner overview](../web_services/scanner.md)** covers the
    ground for now: where the page runs, running a scan, moving a device,
    and where the data lands.

On a hub that runs more than one experiment, start by finding *your*
experiment's scanner on the fleet map's
[Experiment instances](../platform/fleet_map.md#experiment-instances):
each instance has a port of its own, and the main scanner cannot see a
bench's devices.

When this tutorial is written it will be a single guided walkthrough:
configure an experiment, build a save set, run a NOSCAN and a 1D scan,
watch them in the Data Portal, and hand off to the
[analysis tutorial](analysis.md) — plus the advanced moves (optimization
scans, action sequences, presets).
