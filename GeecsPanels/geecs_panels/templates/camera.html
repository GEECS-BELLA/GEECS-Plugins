{# Rung 3: questions answered before anything proceeds. #}

Change the camera ROI?

This changes what every scan with this camera saves, from its next frame.

Release the run lock?

Only if the scan that set it is gone (a killed worker). A running scan keeps saving either way, but loses its protection against changes.
